Reports a GitHub Actions job triggered by pull_request_target or workflow_run that checks out untrusted pull request code while secrets are reachable, in its own steps or through a local reusable workflow (uses: ./.github/workflows/x.yml with secrets: inherit or an explicit secrets: map).

This is the "Pwn Request" pattern documented by GitHub Security Lab: code from a fork runs with the repository's secrets. Reusable-workflow calls are resolved across every file in .github/workflows/, so a call is reported only when its target actually uses secrets.
